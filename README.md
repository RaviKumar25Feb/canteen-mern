# Snacks Ordering App

A modern web application to view and order snacks using **Next.js 13+** and **Tailwind CSS**.  
Users can see available snacks, prices, orders, and place orders via a modal.

---

## Features

- Responsive snack cards with name, price, and orders count
- Place orders via **OrderModal**
- Quantity validation (1–5)
- Fully styled with **Tailwind CSS**
- Easy to extend and customize

---

## Tech Stack

- **Next.js 13+** (React framework)
- **Tailwind CSS** (utility-first CSS framework)
- **React Hooks** (`useState`, `useEffect`)
- **Axios / Fetch** for API calls
